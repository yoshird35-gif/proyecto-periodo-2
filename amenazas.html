Principales amenazas digitales

Las amenazas digitales pueden dañar dispositivos, robar información o engañar a los usuarios. Conocerlas es el primer paso para prevenirlas.

Aprende a reconocerlas

Estas son algunas amenazas frecuentes y cómo reducir sus riesgos.

🦠

Malware

Software malicioso que puede dañar archivos, espiar actividades o robar información.

Prevención: actualiza el sistema y descarga aplicaciones confiables.
🎣

Phishing

Mensajes o páginas falsas que buscan obtener contraseñas y datos confidenciales.

Prevención: verifica el remitente y la dirección web.
🪪

Robo de identidad

Uso de datos personales para hacerse pasar por otra persona.

Prevención: limita los datos públicos y protege tus cuentas.
💳

Fraude electrónico

Engaños digitales que buscan obtener dinero o información.

Prevención: desconfía de premios inesperados y pagos urgentes.
🔒

Ransomware

Programa que bloquea archivos y exige un pago para recuperarlos.

Prevención: conserva copias de seguridad y evita archivos desconocidos.

Regla práctica

Si un mensaje te presiona para actuar inmediatamente, detente y verifica por otro medio.

Más consejos

Preguntas frecuentes
